# Andrew Boswell | Professional Portfolio

A responsive, static professional portfolio designed for GitHub Pages. No build tools, frameworks, or paid hosting required.

## Preview locally
Open `index.html` in a browser. The website works as a static site. Google Fonts will fall back to system fonts without an internet connection.

## Publish to GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `andrew-boswell-portfolio` (or another name).
2. Upload **all files and folders inside this directory** to the repository's root, including `index.html`, `assets/`, and `resumes/`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main**, select **/(root)**, then **Save**.
5. After deployment, GitHub displays your live URL on the Pages settings screen. It will normally be `https://YOUR-USERNAME.github.io/andrew-boswell-portfolio/`.
6. Test the website on mobile and click both resume download links.

## Before publishing
- Confirm that you want your email address and both resumes publicly available. The PDF resumes contain personal contact information.
- Review all employment descriptions and dates for accuracy.
- Case studies are summaries, not public disclosure of company source code, screenshots, or proprietary data.
- Add a LinkedIn URL later if desired.
- The Teams integration is described as in progress. In-development SKU and R&D projects are intentionally not represented as completed.

## Maintenance
Edit text in `index.html` and colors/layout in `assets/styles.css`. Replace PDFs in `resumes/` when updating your resume, keeping the same filenames to preserve links.


PUBLIC CONTACT: The website contact button links to the Google Form. Public PDFs have phone/email removed. Do not upload private resumes to this public repository.
